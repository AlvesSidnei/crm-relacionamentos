# Templates

Esta pasta contém modelos para você copiar e usar.

## Como usar

1. Copie o conteúdo do template
2. Crie um novo arquivo na pasta correta (pessoas/, empresas/, ou indicacoes/)
3. Preencha com os dados reais
4. Salve

## Templates disponíveis

- `pessoa.md` - Para novos contatos
- `empresa.md` - Para novas empresas
- `indicacao.md` - Para novas oportunidades
